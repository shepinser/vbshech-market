# ВБШЕЧ

Учебный интернет-магазин на Python и Flask с базой Microsoft Access. Покупатель выбирает товары, оформляет заказ в ПВЗ и получает его по коду. Реальная оплата не подключена.

## Запуск

Требуются Windows, Python и ODBC-драйвер Microsoft Access одинаковой разрядности.

В PowerShell из папки проекта:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Открыть [http://127.0.0.1:5055](http://127.0.0.1:5055).

Для первого администратора выполнить `.\.venv\Scripts\python.exe manage.py`. Дальнейшие назначения ролей доступны в управлении пользователями.

## Файлы

- `app.py` — запуск, регистрация и вход.
- `commerce.py` — каталог, корзина, заказы и управление.
- `db.py` — подключение к Access.
- `database.accdb` — база данных со связями.
- `templates/` и `static/` — страницы, стили, скрипты и изображения.
- `Документы/` — описание, презентация и диаграммы.
- `screenshots/` — снимки проекта.

Локальные ключи, виртуальное окружение и блокировки Access исключены через `.gitignore`.
